# Appointment Booking App

This is a simple Vue.js app for booking appointments.  

- Users can **signup and login**.  
- After login, users can see their **dashboard** with booked appointments.  
- Users can **book new appointments** or **cancel** existing ones.  
- The app uses **Pinia** for state management.  
- Data is saved in **LocalStorage** so it stays after refresh.  
- Components are **reactive**, so UI updates automatically.  
- **Route guards** protect pages that need login.  

Simple and easy to use!
